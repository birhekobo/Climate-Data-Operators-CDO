# Quiz 1: CDO Basics

**Instructions:** Choose the best answer for each question.

---

**1. What does CDO stand for?**
- A) Climate Data Operators
- B) Common Data Objects
- C) Computer Display Output
- D) Climate and Data Organization

**2. Which command shows the installed CDO version?**
- A) `cdo info`
- B) `cdo --version`
- C) `cdo status`
- D) `cdo help`

**3. Which CDO operator prints information about a dataset (variables, grid, time steps)?**
- A) `info`
- B) `describe`
- C) `sinfo`
- D) `ncdump`

**4. CDO can read and write which of the following file formats?**
- A) NetCDF only
- B) GRIB only
- C) NetCDF, GRIB, and others
- D) CSV only

**5. What is a CDO modifier?**
- A) An operator that modifies variable names
- B) A command-line flag that changes how operators behave
- C) A Python library for climate data
- D) A type of input file

**6. The pipe character (`-`) in a CDO command is used for:**
- A) Commenting out part of a command
- B) Specifying output file format
- C) Reading from stdin or writing to stdout
- D) Separating multiple operators

**7. Which of the following is a valid CDO operator category?**
- A) GRAPHICS
- B) FILE OPERATIONS
- C) DATABASE
- D) WEBSERVER

**8. How does CDO handle datasets that are too large to fit in memory?**
- A) It crashes with an out-of-memory error
- B) It uses streaming/chunked processing
- C) It automatically subsets the data
- D) It requires a supercomputer

**9. Which grid type is most commonly seen in global climate model output processed by CDO?**
- A) triangular
- B) unstructured
- C) lonlat (regular latitude-longitude)
- D) spectral

**10. The `--no_metadata` option in CDO does what?**
- A) Deletes all metadata from the output file
- B) Suppresses metadata headers in ASCII output
- C) Prevents CDO from reading input metadata
- D) Speeds up processing by skipping variable attributes
